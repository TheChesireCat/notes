# Combinatorial characterizations and impossibilities for higher-order homophily

[Link to paper](https://www.science.org/doi/10.1126/sciadv.abq3200)

## Overview

This paper introduces a mathematical framework for measuring homophily in group interactions using hypergraphs, revealing both natural patterns and fundamental combinatorial impossibilities in higher-order social mixing.

## Core Concepts

### Homophily Definition
**Homophily** is the established sociological principle that individuals tend to associate and form connections with other individuals who are similar to them. This principle has been traditionally measured using graph models that only capture pairwise interactions.

### Hypergraph Model
- **Hypergraph** $H = (V, E)$ where:
  - $V$ represents individuals in a population
  - Each hyperedge $e \in E$ represents a group interaction
  - $k$-uniform hypergraph: each hyperedge contains exactly $k$ nodes
  - Class $X \subseteq V$ indicates individuals with the same label (e.g., gender, political affiliation)

## Mathematical Framework

### Type-t Affinity Scores

For a class $X$ and group size $k$, the **type-t affinity score** measures the extent to which individuals in class $X$ participate in groups where exactly $t$ members are from class $X$.

**Key Definitions:**
- **Total degree** $d(v)$: number of groups node $v$ participates in
- **Type-t degree** $d_t(v)$: number of groups with exactly $t$ members from $v$'s class
- **Class degree** $D(X) = \sum_{v \in X} d(v)$
- **Class type-t degree** $D_t(X) = \sum_{v \in X} d_t(v)$

**Type-t Affinity Score:**
$$h_t(X) = \frac{D_t(X)}{D(X)} = \frac{\sum_{v \in X} d_t(v)}{\sum_{v \in X} d(v)}$$

### Baseline Scores

**Standard Baseline Score:**
$$\hat{b}_t(X) = \frac{\binom{|X|-1}{t-1}\binom{n-|X|}{k-t}}{\binom{n-1}{k-1}}$$

This represents the probability that a class $X$ node joins a type-$t$ group if other nodes are selected uniformly at random.

**Asymptotic Baseline Scores:**
For class proportion $\alpha = |X|/n$:
$$b_t(X) = \alpha^{t-1}(1-\alpha)^{k-t}\binom{k-1}{t-1}$$

### Ratio Scores

**Ratio Score:**
$$\frac{h_t(X)}{b_t(X)}$$

- Ratio > 1: type-$t$ interactions are overexpressed
- Ratio ≈ 1: interactions occur roughly as expected by chance
- Ratio < 1: type-$t$ interactions are underexpressed

## Types of Higher-Order Homophily

### Simple Homophily
Class $X$ exhibits **simple homophily** if $h_k(X) > b_k(X)$ (higher-than-baseline affinity for groups containing only members of their class).

### Order-j Majority Homophily
Class $X$ exhibits **order-j majority homophily** if the top $j$ affinity scores are higher than baseline:
$$h_{k-j+1}(X) > b_{k-j+1}(X), h_{k-j+2}(X) > b_{k-j+2}(X), \ldots, h_k(X) > b_k(X)$$

### Order-j Monotonic Homophily
Class $X$ exhibits **order-j monotonic homophily** if ratio scores are strictly increasing:
$$\frac{h_t(X)}{b_t(X)} > \frac{h_{t-1}(X)}{b_{t-1}(X)} \text{ for } t \geq k-j+1$$

### Strict Notions

**Strict Majority Homophily:** Higher-than-random affinities for groups where the class constitutes a majority ($t > k-t$).

**Strict Monotonic Homophily:** Ratio scores strictly increasing for majority groups.

## Key Impossibility Theorems

### Theorem 3: Strict Monotonic Homophily (Odd k)
For odd $k$, it is **combinatorially impossible** for both classes in a two-class hypergraph to simultaneously exhibit strict monotonic homophily.

**Proof Sketch:**
- Assumes both classes exhibit strict monotonic homophily
- Derives two contradictory inequalities involving hyperedge counts
- Shows $\frac{m_r}{M_r} > \frac{m_{r-1}}{M_{r-1}}$ and $\frac{m_{r-1}}{M_{r-1}} > \frac{m_r}{M_r}$ where $r = \frac{k+1}{2}$

### Theorem 4: Strict Monotonic Homophily (Even k)
For even $k$, impossible under additional constraint $\frac{h_\ell(X)}{b_\ell(X)} > \frac{h_{\ell-1}(X)}{b_{\ell-1}(X)}$ for one class, where $\ell = k/2$.

### Theorem 5: Strict Majority Homophily
- **Odd k:** Impossible for both classes simultaneously
- **Even k:** Impossible if additionally $h_{k/2}(X) > b_{k/2}(X)$ for one class

**Proof Strategy:** Uses linear programming duality to show no feasible solution exists.

## Alternative Measures

### Alternative Affinity Scores
$$\tilde{h}_t(A) = \frac{m_t}{\sum_{i=1}^k m_i}, \quad \tilde{h}_t(B) = \frac{m_{k-t}}{\sum_{i=1}^k m_{k-i}}$$

### Normalized Bias Scores
$$f_t(X) = \begin{cases}
\frac{h_t(X) - b_t(X)}{1 - b_t(X)} & \text{if } h_t(X) \geq b_t(X) \\
\frac{h_t(X) - b_t(X)}{b_t(X)} & \text{if } h_t(X) < b_t(X)
\end{cases}$$

Values range from -1 to 1, providing comparable measures across datasets.

## Homophily Indices

### Majority Homophily Index (MaHI)
Maximum $j$ such that order-$j$ majority homophily holds.

### Monotonic Homophily Index (MoHI)  
Maximum $j$ such that order-$j$ monotonic homophily holds.

## Empirical Applications

### Political Homophily in Legislative Bills
- **Dataset:** U.S. Congress bill cosponsorship
- **Classes:** Democrats vs Republicans
- **Findings:** 
  - Both parties exhibit bowl-shaped ratio curves
  - MoHI values at combinatorial limits
  - Strong overexpression of highly imbalanced groups

### Academic Collaboration
- **Dataset:** Computer science publications
- **Classes:** Male vs female authors
- **Findings:**
  - Women exhibit monotonic homophily for 3-4 author papers
  - Men do not exhibit strict monotonic homophily
  - Differences partly due to combinatorial constraints

### Location Homophily in Hotel Reviews
- **Dataset:** TripAdvisor hotel reviews
- **Classes:** North America vs Europe
- **Findings:** Users tend to review hotels in same geographic region

### Product Homophily in Shopping
- **Dataset:** Walmart shopping baskets  
- **Classes:** Clothing vs Groceries
- **Findings:** Shopping trips focus primarily on one product category

### Gender Distribution in Group Photos
- **Dataset:** Family, wedding, and group photos
- **Context-dependent patterns:**
  - Wedding photos: Low same-gender pairs (bride/groom effect)
  - Family photos: Gender-balanced groups more common
  - General group photos: Higher same-gender homophily

## Key Insights

### Combinatorial Constraints Shape Behavior
Many observed differences between groups are not due to social preferences but to mathematical impossibilities that constrain what patterns can exist.

### Bowl-Shaped Ratio Curves
Common empirical pattern where:
- Slight majority groups are underexpressed
- Extreme majority/minority groups are overexpressed
- Reflects combinatorial necessities rather than social preferences

### Graph vs Hypergraph Measures
Traditional graph homophily measures miss nuanced patterns visible only in group interaction data.

## Linear Programming Framework

### Primal LP for Maximum Homophily
$$\max \gamma \text{ subject to constraints encoding affinity bounds}$$

### Key Results
- $\gamma^* > 0$ iff strict majority homophily possible for both classes
- Dual LP provides certificates of impossibility
- Framework generalizable to other homophily notions

## Practical Implications

### Interpretation Guidelines
1. **Consider combinatorial limits** when interpreting homophily measures
2. **Use normalized bias scores** for cross-dataset comparisons  
3. **Examine multiple group sizes** to understand full homophily patterns
4. **Account for baseline effects** in heterogeneous populations

### Methodological Recommendations
1. Apply framework to each group size separately
2. Use asymptotic baselines for large datasets
3. Consider alternative affinity score definitions
4. Validate findings against combinatorial impossibilities

## Future Directions

1. **Multi-class extensions** beyond two-class hypergraphs
2. **Dynamic homophily** in evolving group structures  
3. **Higher-order monophily** and other mixing patterns
4. **Aggregate measures** across multiple group types and sizes

## Summary

This framework reveals that higher-order homophily is governed by fundamental combinatorial constraints independent of human behavior. While intuitive notions like "both groups preferring same-class interactions" seem reasonable, they are often mathematically impossible. The framework provides tools to measure meaningful group homophily patterns while respecting these constraints, offering deeper insights into social group formation than traditional pairwise approaches.
